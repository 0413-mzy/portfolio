# Cheat Sheets

This folder stores quick-reference materials for Python, data science, machine learning, and common analytical libraries. The files are intended for revision, coursework support, and fast lookup while working on notebooks or data projects.

## How To Use

- Use these files as quick references when writing Python code or Jupyter notebooks.
- Start with Python and Jupyter materials if you are reviewing fundamentals.
- Use NumPy and Pandas sheets for data cleaning, transformation, and analysis.
- Use Matplotlib and Seaborn sheets when building charts.
- Use scikit-learn and Keras sheets when reviewing machine learning workflows.
