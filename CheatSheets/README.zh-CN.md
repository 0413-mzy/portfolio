# 速查表

这个文件夹保存 Python、数据科学、机器学习和常用分析库的速查资料。它适合复习、辅助课程学习，以及在写 notebook 或数据项目时快速查找语法和常见流程。

English version: [README.md](README.md).

## 如何使用

- 写 Python 代码或 Jupyter notebook 时，可以把这些文件当作快速参考。
- 如果要复习基础，先看 Python 和 Jupyter 相关资料。
- 做数据清洗、转换和分析时，看 NumPy 与 Pandas 相关资料。
- 做图表时，看 Matplotlib 与 Seaborn 相关资料。
- 复习机器学习流程时，看 scikit-learn 与 Keras 相关资料。
