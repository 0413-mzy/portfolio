# Applied Data Science

这个文件夹保存 Applied Data Science 相关课程的期末报告 notebook。文件使用 Jupyter Notebook 格式，因此可以在同一份文档中展示代码、输出结果和文字分析。

English version: [README.md](README.md).

## 文件

- `ADS1001_FinalReport.ipynb`
  - ADS1001 的期末报告 notebook。
  - 用于展示完整的数据分析流程，包括代码、输出结果和文字解释。

- `ADS1002_FinalReport.ipynb`
  - ADS1002 的期末报告 notebook。
  - 用于记录分析过程，并以报告形式表达分析结果。

## 这些 notebook 展示的能力

- 使用 Python 处理数据。
- 使用 Jupyter Notebook 进行可复现分析。
- 结合代码、可视化输出和文字说明。
- 按期末报告结构组织分析内容。
- 清晰表达数据驱动的结论。

## 如何打开

可以用以下方式查看 notebook：

- 直接在 GitHub 上打开。
- 下载仓库后，用 JupyterLab 或 Jupyter Notebook 打开。
- 在 VS Code 中安装 Jupyter 扩展后打开。

## 说明

这些 notebook 是课程作业成果，主要用于展示学习过程、分析思路和数据科学报告写作能力。
