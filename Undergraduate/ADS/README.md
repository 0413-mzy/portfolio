# Applied Data Science

This folder contains final report notebooks for Applied Data Science coursework. The notebooks are kept in Jupyter Notebook format so they can show both code and written analysis in the same document.

中文说明请见 [README.zh-CN.md](README.zh-CN.md).

## Files

- `ADS1001_FinalReport.ipynb`
  - Final report notebook for ADS1001.
  - Intended to present a complete data analysis workflow, including code, outputs, and written interpretation.

- `ADS1002_FinalReport.ipynb`
  - Final report notebook for ADS1002.
  - Intended to document the analysis process and communicate findings in a report-style format.

## What These Notebooks Demonstrate

- Working with data in Python.
- Using Jupyter Notebook for reproducible analysis.
- Combining code, visual output, and written explanation.
- Structuring analysis as a final report.
- Communicating data-driven findings clearly.

## How To Open

You can view the notebooks in several ways:

- Open them directly on GitHub.
- Download the repository and open them with JupyterLab or Jupyter Notebook.
- Open them in VS Code with the Jupyter extension.
