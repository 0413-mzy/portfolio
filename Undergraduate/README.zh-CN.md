# 本科阶段资料

这个文件夹保存本科阶段的部分学习材料。内容按课程或主题分类，包括数据科学 notebook 和课程作品集 PDF。

English version: [README.md](README.md).

## 文件夹

- `ADS`
  - Applied Data Science 相关课程作业。
  - 包含 ADS1001 和 ADS1002 的期末报告 notebook。
  - 说明见 [ADS/README.zh-CN.md](ADS/README.zh-CN.md)。

- `FIT`
  - FIT1045 课程作品集材料。
  - 包含两个 PDF 文件，合起来组成完整作品集。
  - 说明见 [FIT/README.zh-CN.md](FIT/README.zh-CN.md)。

## 如何查看

- `.ipynb` notebook 可以直接在 GitHub、JupyterLab 或 VS Code 中打开。
- `.pdf` 文件可以在浏览器中打开，也可以下载后本地阅读。

这个文件夹中的材料反映了本科课程学习成果，主要作为学术归档保存。部分内容会遵循原课程要求。
