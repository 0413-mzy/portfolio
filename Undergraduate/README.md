# Undergraduate

This folder contains selected materials from my undergraduate studies. It is organized by course or subject area, with data science notebooks and portfolio PDFs stored in separate folders.

中文说明请见 [README.zh-CN.md](README.zh-CN.md).

## Folders

- `ADS`
  - Applied Data Science coursework.
  - Contains final report notebooks for ADS1001 and ADS1002.
  - See [ADS/README.md](ADS/README.md).

- `FIT`
  - FIT1045 portfolio materials.
  - Contains two PDF files that together form the full portfolio.
  - See [FIT/README.md](FIT/README.md).

## How To View

- Open `.ipynb` notebooks directly on GitHub, in JupyterLab, or in VS Code.
- Open `.pdf` files in the browser or download them for local reading.

## Notes

The materials in this folder reflect coursework and learning outcomes from undergraduate study. They are kept as an academic archive and may follow the requirements of their original courses.
