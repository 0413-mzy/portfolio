# 作品集

这个仓库用于整理我的学术作品集、数据科学课程作业、学习笔记和常用参考资料。它主要是一个本科阶段学习成果的归档仓库，也用于保存以后可以反复查阅的学习资源。

English version: [README.md](README.md).

## 仓库内容

### 本科阶段作品

`Undergraduate` 文件夹中保存了本科阶段的部分课程作业和作品集材料。

- `Undergraduate/ADS`
  - Applied Data Science 相关课程的期末报告，文件格式为 Jupyter Notebook。
  - 包含 `ADS1001_FinalReport.ipynb` 和 `ADS1002_FinalReport.ipynb`。
  - 这些 notebook 展示了数据分析流程、探索性数据分析、建模步骤，以及报告式表达。

- `Undergraduate/FIT`
  - FIT1045 课程作品集 PDF 文件。
  - 为了方便存储和查看，作品集被拆分成两个 PDF 文件。

### 速查表

`CheatSheets` 文件夹中保存了 Python 和数据科学相关工具的参考资料，包括：

- Python 基础
- Jupyter Notebook 基础
- NumPy
- Pandas
- Matplotlib
- Seaborn
- SciPy 线性代数
- scikit-learn
- Keras

这些资料适合在复习、写作业、做数据分析项目时快速查找语法、概念和常见工作流。

## 如何查看文件

- Markdown 文件可以直接在 GitHub 上查看。
- Jupyter Notebook 文件可以直接在 GitHub、JupyterLab 或 VS Code 中打开。
- PDF 文件可以在浏览器中直接打开，也可以下载后离线阅读。
