# Portfolio

This repository collects my academic portfolio, data science coursework, learning notes, and reference materials. It is mainly used as a structured archive of my undergraduate work and as a place to keep reusable study resources.

中文说明请见 [README.zh-CN.md](README.zh-CN.md).

## What Is Inside

### Undergraduate Work

The `Undergraduate` folder contains selected coursework and portfolio materials from my undergraduate studies.

- `Undergraduate/ADS`
  - Applied Data Science final reports in Jupyter Notebook format.
  - Includes `ADS1001_FinalReport.ipynb` and `ADS1002_FinalReport.ipynb`.
  - These notebooks demonstrate data analysis workflows, exploratory analysis, modelling steps, and report-style communication.

- `Undergraduate/FIT`
  - FIT1045 portfolio PDF files.
  - The portfolio is split into two PDF parts for easier storage and viewing.

### Cheat Sheets

The `CheatSheets` folder contains reference materials for Python and data science tools, including:

- Python basics
- Jupyter Notebook basics
- NumPy
- Pandas
- Matplotlib
- Seaborn
- SciPy linear algebra
- scikit-learn
- Keras

These files are useful for quick revision and for looking up common syntax, concepts, and workflows while studying or working on data-related projects.

- Markdown files can be viewed directly on GitHub.
- Jupyter Notebook files can be opened directly on GitHub, in JupyterLab, or in VS Code.
- PDF files can be opened directly in the browser or downloaded for offline reading.
